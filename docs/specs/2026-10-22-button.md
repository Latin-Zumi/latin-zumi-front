# Spec: Componente Button con Spinner

## Fecha
2026-10-23

## Problema
Necesitamos un botón reutilizable que soporte variantes (`solid`, `link`), tamaños (`sm`, `md`, `lg`) y estados (`disabled`, `loading`). Actualmente no existe un componente estándar que combine accesibilidad, consistencia visual y feedback de carga.

## Solución propuesta
Implementar un componente `Button` en React y TypeScript:
- Definir una API tipada con las props `variant`, `size`, `onClick`, `disabled`, `loading`, `href` y `target`.
- Renderizar un `<button>` para la variante `solid` y mostrar `<Spinner size="sm" />` junto con el texto `"Cargando…"` durante la carga.
- Renderizar un `<a>` para la variante `link`, con soporte para `href` y `target`.
- Reutilizar el componente `Spinner` y aplicar las clases globales `btn`, `btn-link` y `btn-{size}`.

## Archivos afectados
- `src/components/ui/Button.tsx`
- `src/components/ui/Spinner.tsx`
- `tests/Button.test.tsx`

## Pasos
1. Definir los tipos `ButtonBaseProps`, `SolidButtonProps` y `LinkButtonProps`.
2. Crear la unión `ButtonProps`.
3. Implementar el renderizado condicional según la variante.
4. Integrar `Spinner` en el estado `loading`.
5. Exportar el componente.

## Cómo probar
- [ ] Renderizar `<Button variant="solid">Guardar</Button>` y verificar que muestre un `<button>` con la clase `btn btn-md`.
- [ ] Renderizar `<Button variant="solid" loading>Guardar</Button>` y verificar que muestre `<Spinner size="sm" />` y `"Cargando…"`.
- [ ] Renderizar `<Button variant="link" href="/home">Inicio</Button>` y verificar que muestre un `<a>` con la clase `btn-link btn-md`.
- [ ] Verificar que `disabled` deshabilite el botón en la variante `solid`.

## Riesgos / notas
- Depende de que las clases `btn`, `btn-link` y `btn-{size}` estén definidas en `global.css`.
- Como posible extensión futura, se pueden añadir variantes de color (`primary`, `secondary`) o íconos.

# Spec: Vista Home de Latin Zumi

# Fecha
2026-10-26

# Problema
La aplicación necesita una pantalla inicial que muestre información útil (cotizaciones de monedas) incluso a usuarios no autenticados, pero que restrinja las operaciones (depositar, transferir, cambiar moneda) únicamente a quienes hayan iniciado sesión o creado una cuenta.

#Solución propuesta
Implementar un componente Home que:

Muestre el logo y un mensaje de bienvenida.

Liste las cotizaciones actuales de las monedas soportadas (USD, EUR, ARS, COP).

Si el usuario no está autenticado:

Mostrar solo las cotizaciones.

Bloquear acciones y mostrar botones de login/register.

Si el usuario está autenticado:

Mostrar además el resumen de su billetera (balances).

Habilitar botones de acción: Depositar, Transferir, Cambiar moneda.

# Archivos afectados
src/views/Home.tsx

src/App.tsx (para agregar la ruta /)

src/global.css (estilos para .home, .rates, .actions)

# Pasos
Crear componente Home con estructura <main>.

Definir sección de cotizaciones (rates).

Condicionar acciones según isAuthenticated.

Conectar la ruta / en App.tsx → <Route path="/" element={<Home />} />.

Agregar estilos globales para presentación clara.

# Cómo probar
[ ] Navegar a / sin usuario → deben mostrarse cotizaciones y botones de login/register.

[ ] Navegar a / con usuario → deben mostrarse cotizaciones, balances y botones de acción habilitados.

[ ] Verificar que las acciones redirigen a login/register si no hay sesión.

[ ] Verificar que las acciones funcionan si el usuario está autenticado.

# Riesgos / notas
Las cotizaciones deben actualizarse dinámicamente (futuro: integrar API de precios).

El Home debe ser liviano y rápido de cargar, ya que es la primera impresión del usuario.

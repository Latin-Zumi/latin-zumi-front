# Spec: Header para la billetera

# Fecha
2026-10-24

# Problema
La aplicación necesita un encabezado consistente que muestre la marca, la navegación principal y las acciones de cuenta, adaptado al contexto de una billetera virtual.

# Solución propuesta
Implementar un componente Header que:

Muestre el logo y enlace a inicio.

Muestre navegación básica: Inicio, Mi billetera (solo si el usuario está autenticado), Panel admin (solo si es admin).

Muestre acciones de cuenta: login/register o identidad + logout.

Use Spinner mientras se verifica sesión.

# Archivos afectados
src/components/layout/Header.tsx

# Pasos
Definir navegación principal con NavLink.

Condicionar enlaces según estado de autenticación y rol.

Mostrar spinner mientras se verifica sesión.

Mostrar botón de logout cuando el usuario esté autenticado.

Exportar el componente.

# Cómo probar
[ ] Renderizar sin usuario → debe mostrar botones de login/register.

[ ] Renderizar con usuario → debe mostrar “Mi billetera” y botón de logout.

[ ] Renderizar con admin → debe mostrar enlace a “Panel admin”.

[ ] Verificar que el spinner aparezca cuando authState.status === "loading".

# Riesgos / notas
El header debe ser liviano y adaptado al flujo de la billetera.

El logo debe ser consistente con la marca Latin Zumi.

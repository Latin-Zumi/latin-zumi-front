# Spec: Footer de Latin Zumi

# Fecha
2026-10-26

# Problema
La aplicación necesita un pie de página consistente que acompañe al Layout principal, mostrando créditos y enlaces secundarios. Actualmente el Layout ya incluye Header y Footer, pero falta definir el contenido y estilo del Footer.

# Solución propuesta
Implementar un componente Footer que:

Muestre créditos con el año dinámico y el nombre de la billetera.

Incluya enlaces secundarios (ej. soporte, redes sociales, documentación).

Se integre en el Layout debajo del main.

# Archivos afectados
src/components/layout/Footer.tsx

src/components/layout/Layout.tsx (ya lo referencia)

src/global.css (estilos para .site-footer)


# Pasos
Crear componente Footer con estructura <footer>.

Incluir créditos dinámicos con © {new Date().getFullYear()} Latin Zumi · Billetera Digital.

Agregar navegación secundaria (footer-nav) con enlaces a soporte y redes.

Confirmar integración en Layout (ya implementada).

# Cómo probar
[ ] Renderizar cualquier ruta pública (/login, /register, /dashboard) → debe mostrar el footer al final.

[ ] Verificar que el año se actualiza dinámicamente.

[ ] Verificar que los enlaces secundarios funcionan y abren en nueva pestaña si son externos.

[ ] Verificar que el footer no aparece en /admin.

# Riesgos / notas
El footer debe ser liviano y no interferir con la navegación principal.

Los enlaces secundarios deben ser opcionales y fáciles de extender.

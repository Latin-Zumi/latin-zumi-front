# Spec: Chatbot del asistente

## Fecha
2026-11-04

## Problema
El back tiene `POST /chat/messages`, un asistente con Gemini que responde con los saldos y movimientos del usuario, pero el front no tiene forma de usarlo.

## Solución propuesta
Una burbuja flotante, abajo a la derecha, en las pantallas que no son del panel de admin:

- **Quién la ve:** solo quien tiene sesión, porque el back exige token. No aparece si el back pide cambiar la contraseña.
- **Compu y celular:** se abre como una ventana sobre la pantalla; en el celular ocupa toda la pantalla.
- **Conversación:** dura mientras la sesión sigue abierta y la página no se recarga. El back no la guarda, así que el front le manda los últimos 10 mensajes, recortados a 2000 caracteres. Al cambiar de usuario o cerrar sesión, se borra.
- **Sugerencias:** las que manda el back se muestran como botones. Al abrir, hay dos fijas.
- **Errores:** usa mensajes propios, porque el `503` del back puede traer el error interno del proveedor. Si falla, el mensaje vuelve al campo para reenviarlo. Un `401` cierra la sesión.
- **Texto:** las respuestas se muestran como texto, sin interpretar HTML ni Markdown.
- **Aviso:** indica que responde con inteligencia artificial, usando los saldos y movimientos del usuario.
- **Mock:** responde con los saldos del usuario, sin inteligencia artificial.

`CHATBOT_ENABLED` lo deja solo en modo mock hasta confirmar lo que falta del back.

## Cómo probar
- [x] `npm test`, `npm run lint` y `npm run build` pasan.
- [x] Con `VITE_USE_MOCK=true`: la burbuja aparece con sesión y no sin ella.
- [x] Con `VITE_USE_MOCK=true`: enviar con Enter, usar una sugerencia y bajar de línea con Shift+Enter.
- [x] En 375 px ocupa toda la pantalla, sin desbordarse a lo ancho.
- [ ] Con la API real: responde con los saldos de la cuenta y mantiene el contexto entre mensajes.
- [ ] Con la API real: si el asistente no está disponible, muestra el mensaje propio.

## Riesgos / notas
Antes de prender `CHATBOT_ENABLED` con la API real:

1. Confirmar `GEMINI_API_KEY` en Render; sin ella, el chat responde `503`.
2. Agregar un límite de pedidos a `/chat/messages`: hoy no tiene, y cada mensaje consume Gemini.
3. Sacar el error interno del proveedor del mensaje del `503`.
4. Aprobar que los saldos y movimientos se manden a Gemini, e informarlo en los términos de la app.

La conversación se pierde al recargar la página.

# Spec: Input genérico para la billetera

# Fecha
2026-10-24

# Problema
La billetera necesita un campo de entrada genérico y reutilizable para formularios (ej. login, depósitos, transferencias).

# Solución propuesta
Implementar un componente Input configurable:

Aceptar label opcional para accesibilidad.

Aceptar placeholder para guiar al usuario.

Aceptar type (text, email, password, number).

Aceptar disabled para estados inactivos.

Aceptar error para mostrar mensajes de validación.

Usar atributos de accesibilidad (aria-invalid, aria-describedby).

# Archivos afectados
src/components/ui/Input.tsx

tests/Input.test.tsx

# Pasos
Definir las props del componente (label, placeholder, value, onChange, type, disabled, error).

Renderizar el campo de entrada con estilos consistentes.

Mostrar el mensaje de error cuando se pase la prop error.

Añadir atributos de accesibilidad.

Exportar el componente.

# Cómo probar
[ ] Renderizar Input con type="text" y verificar que se muestre correctamente.

[ ] Renderizar con disabled y verificar que no se pueda escribir.

[ ] Renderizar con error="Campo requerido" y verificar que aparezca el mensaje y aria-invalid.

[ ] Verificar que el label se muestre cuando se pasa la prop.

# Riesgos / notas
El error debe ser claro y conciso.

El componente debe ser reutilizable en cualquier formulario de la billetera.

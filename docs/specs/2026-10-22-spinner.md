# Spec: Componente Spinner

## Fecha
2026-10-23

## Problema
Necesitamos un indicador de carga reutilizable y accesible para mostrar estados de espera en la interfaz. Actualmente no existe un componente estándar que cumpla con los requisitos de accesibilidad y soporte distintos tamaños.

## Solución propuesta
Implementar un componente `Spinner` en React y TypeScript:
- Definir una API con las props `size` y `label`.
- Renderizar un `<span>` con las clases `ui-spinner` y `ui-spinner--{size}`.
- Añadir `role="status"` y `aria-label` para lectores de pantalla.
- Usar `size="md"` y `label="Cargando"` como valores predeterminados.

## Archivos afectados
- `src/components/ui/Spinner.tsx`
- `src/styles/global.css` (clases `ui-spinner` y variantes de tamaño)
- `tests/Spinner.test.tsx`

## Pasos
1. Definir el tipo `SpinnerSize` con los valores `"sm"`, `"md"` y `"lg"`.
2. Crear el componente `Spinner` con props tipadas.
3. Aplicar clases dinámicas según el tamaño.
4. Añadir los atributos de accesibilidad `role` y `aria-label`.
5. Exportar el componente por defecto.

## Cómo probar
- [ ] Renderizar `<Spinner />` sin props y verificar que use el tamaño `md` y la etiqueta `"Cargando"`.
- [ ] Renderizar `<Spinner size="sm" />` y verificar que aplique la clase `ui-spinner--sm`.
- [ ] Renderizar `<Spinner label="Loading data" />` y verificar que tenga `aria-label="Loading data"`.
- [ ] Verificar que el componente se renderice con `role="status"`.

## Riesgos / notas
- Es necesario definir las clases CSS `ui-spinner`, la animación de rotación y las variantes de tamaño.
- Sin estas clases en `global.css`, el componente no tendrá apariencia visual.
- Como posible extensión futura, se pueden añadir colores o variantes de animación.

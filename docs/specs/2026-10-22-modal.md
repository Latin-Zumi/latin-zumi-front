# Spec: Componente Modal accesible

## Fecha
2026-10-22

## Problema
La aplicación necesita un modal reutilizable y accesible para mostrar contenido, un título y un pie personalizable. También debe permitir el cierre con la tecla Escape o al hacer clic en el fondo.

## Solución propuesta
Implementar un componente `Modal` para el sistema de UI:
- Permitir configurar el título, el contenido y el pie.
- Permitir cerrar el modal con Escape o al hacer clic en el fondo, según las props correspondientes.
- Mover el foco al modal y restaurarlo al cerrarlo.
- Bloquear el scroll de la página mientras el modal está abierto.

## Archivos afectados
- `src/components/ui/Modal.tsx`
- `tests/Modal.test.tsx`

## Pasos
1. Crear el componente `Modal` con props para controlar su apertura y cierre.
2. Implementar el overlay, el contenido, el título y el pie personalizable.
3. Añadir el cierre configurable con Escape y con clic en el fondo.
4. Implementar el manejo del foco y el bloqueo del scroll.
5. Exportar el componente.

## Cómo probar
- [ ] Renderizar `<Modal isOpen={true} />` y verificar que muestre el overlay y el contenido.
- [ ] Presionar Escape y verificar que ejecute `onClose` cuando `closeOnEscape` sea `true`.
- [ ] Hacer clic en el fondo y verificar que ejecute `onClose` cuando `closeOnBackdrop` sea `true`.
- [ ] Verificar que el foco se mueva al modal y se restaure al cerrarlo.
- [ ] Renderizar el modal con `title` y `footer` y verificar que muestre el encabezado y el pie personalizados.

## Riesgos / notas
- El cierre mediante Escape y mediante clic en el fondo debe poder configurarse de forma independiente.
- El manejo del foco y del scroll debe mantenerse consistente al abrir y cerrar el modal.
